# GitHub-Only Modules (Archived)

These modules depend on GitHub-only platform features. They are kept for
design history only; the orchestrator does not discover them.

| Module | Outcome |
| --- | --- |
| `forgejo-intelligent-code-review` | Folded into `forgejo-intelligent-pull-request`. |
| `forgejo-intelligent-codespace` | Replaced by `forgejo-intelligent-dev-environment`. |
| `forgejo-intelligent-deployment` | Retired until a validated Forgejo deployment integration exists. |
| `forgejo-intelligent-discussion` | Retired. No native Forgejo Discussions unit. |
| `forgejo-intelligent-mention` | Folded into issue and pull request surfaces. |
| `forgejo-intelligent-sponsor` | Retired. No native Forgejo Sponsors equivalent. |

See `.forgejo-intelligence/help/unsupported-github-surfaces.md` for the rule
governing new surfaces.
