# Deferred Modules

Modules here are not GitHub-only; they are deferred until their behavior is
specified, fixture-backed, and reviewed for the Forgejo runtime. The
orchestrator does not discover them.

| Module | Status |
| --- | --- |
| `forgejo-intelligence-emergency` | Deferred. |

Reinstatement follows the rule in
`.forgejo-intelligence/help/unsupported-github-surfaces.md`: a README
describing Forgejo trigger, API calls, state files, and unsupported GitHub
behavior, plus tests or fixtures for the event shape.
