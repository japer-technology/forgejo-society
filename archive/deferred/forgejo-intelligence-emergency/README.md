# forgejo-intelligence-emergency (deferred)

This module is archived under `archive/deferred/`. It is not GitHub-only; it is
deferred until its behavior is specified, fixture-backed, and reviewed for the
Forgejo runtime. The orchestrator does not discover it.

## Reinstatement rule

A deferred module returns to `.forgejo-intelligence/` only when it has a
README describing its Forgejo trigger, API calls, state files, and unsupported
GitHub behavior, plus tests or fixtures for its event shape, per
`.forgejo-intelligence/help/unsupported-github-surfaces.md`.
